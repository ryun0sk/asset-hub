## 調査の前提

ユーザーの「これまでの分析と今の市況を踏まえ、私が考える買い価格を示してほしい」という依頼に対する再検討。1〜3年程度の現物保有を想定した購入基準で、短期の底値・反発時期の予想ではない。

- 調査日は2026年10月15日（日本時間）。株価は取得ページに表示された同日10:18の13,175円を使用。終値ではなく、その後の最終価格でもない。
- 株価・EPS・評価額は円建て、2026年10月1日効力の1対3分割後で統一する。
- 株数は8月31日現在の発行済株式から自己株式を控除し、分割後換算した1,597,515,021株。9月末確定株数ではない。
- 会社の通期利益予想は未公表。IFISの2027年3月期予想は外部集計として区別する。
- 評価モデルのCF、要求収益率、安全余裕、購入価格はすべて独自仮定。市場予想の下方修正や会社ガイダンス変更と混同しない。
- 前回のCFケースは比較用に残し、買付判断には別の慎重ケースを使う。前回資料を上書きしない。
- TrendForceの10月7日・9月16日調査は公開要旨のみ確認。有料の全文は取得していない。
- PDF資料の数値を照合したが、新たなPDFの生成・再編集はしていない。外部資料は[出典一覧](related-links.md)から参照できる。
- X API、有料API、秘密情報は使用していない。売買・commit・push・公開は行っていない。

## 再計算

```sh
node research/companies/285A-kioxia/2026-10-15/valuation.mjs
```

標準ライブラリのみ。外部通信やファイル書き込みは行わない。出力を保存したものがvaluation.json。

実績推移は、保存した入力を使い、`python3 eps-per-history.py --no-chart`でJSON/CSVを再生成できる。PNG/SVGの描画にはmatplotlibを使う。株価・決算の入力はeps-per-history-inputs.jsonに保存し、外部ネットワークを使わず再計算できる。
