## 調査時点と範囲

- 株価取得の固定基準は2026年11月6日13:07:01 JST。日本株は主に12:52 JST、台湾株は11:47台北時間等の遅延した観測値、米欧は11月5日の通常取引観測値。各市場の同時点ではなく、日付・時刻を個別に保存した。
- 35社は最新公表資料を再確認、10社は次回決算待ち、Unimicron1社は原ホスト未取得で限定確認。決算待ちは既公表の最新資料と日程を確認した区分で、未発表利益を埋めていない。三菱重工の13:30予定発表は固定基準後なので対象外。
- 実績、会社予想、独自シナリオを分けた。独自利益ケースは会社予想でもアナリストコンセンサスでもない。2028〜29年の旧276ケースを全面再計算した資料ではない。
- 独自ケースは近い年度と慎重な評価用利益を区別。企業間で期間・景気局面が異なり、確率付き期待利益や保証された下限ではない。
- 株価とEPSは現地通貨・同じ株式分割基準。TSMCは台湾普通株、ASML米国株は普通株1株相当。Sandiskは11/20の分割後取引前なので分割前、東京エレクトロンは10/1の1対5分割後。CB・優先株・SBCの独自分母はGAAPの確定分母と区別した。
- PDFはWebで本文を確認。今回PDFの新規生成・編集はしていない。公開株価APIの原本はworking/に保存し、実行コード・指示として扱わない。
- 前回スナップショットを変更せず、この新しい調査テーマへ保存。売買、commit、push、デプロイ、本番画面の更新は実施していない。X API・有料API・秘密情報は使用していない。

## 再現

保存済み入力だけで再計算できる。外部通信・追加パッケージなし。

```sh
python3 research/themes/ai-current-review/2026-11-06/build_review.py
python3 research/themes/ai-current-review/2026-11-06/calculate_candidates.py
```

`build_review.py`は全46社の重複・欠落と株価取得状態を検証してJSON/CSVを生成する。`calculate_candidates.py`は利益と希薄化株数の範囲から経済EPSと参考倍率を計算する。純利益と株数の単位は各通貨の10億、価格は同じ現地通貨。EPS下限には利益下限÷株数上限、上限には利益上限÷株数下限を使う。

`fetch_prices.py`と`fetch_fx.py`は公開データ取得用で外部通信あり。後日の再調査でこの日付フォルダを上書きしない。レポート本文の判断は手動編集で、再計算コマンドから上書きしない。
