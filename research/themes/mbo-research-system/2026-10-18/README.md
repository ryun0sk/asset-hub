# MBO候補と割安度を調べるシステムの設計

設計日：2026-10-18（日本時間）。日本の上場普通株を対象に、MBO候補の探索、企業価値の評価、出典確認を行う個人用システムの計画。同日のユーザー指定により、追加の有料データ契約・クラウド計算・従量課金AIを使わない無料版を現行案とした。既存Macと回線を使い、資料の持込だけでも動くローカル構成を基礎にする。

同日、ユーザーの「この手元PCで毎週依頼する」運用を前提に初版を実装した。[起動・週次の手順と実装範囲](../../../../docs/mbo-weekly.md)から利用できる。CSV取込、DCF/LBO、候補・公表案件の分離、前回差分とローカル画面に対応。資料の数値確認は人が行い、PDF/XBRL自動抽出とEDINET自動取得は未実装。

続く依頼で、普段の非公開Asset Hubの「MBO調査」タブにも反映した。計算・原本保存はMacのまま、クラウドは閲覧用に選別した週次結果だけを表示する。[タブ統合と本番検証](../../../../docs/changes/2026-10-18-mbo-tab/README.md)を参照。

設計の主担当はユーザー指定のGPT-6 Astra。Codexが既存Asset Hubとの接続と公式データ仕様を確認し、独立した検証担当のレビューを統合した。

- 初版は架空データで取込・計算・履歴・画面を検証。実企業の初回投入、実際の割安判定、MBO確率、投資成果はまだ算出していない。
- 料金とデータ仕様は2026-10-18に閲覧できた公式資料による。設計の保存によってデータ契約、APIキーの取得、課金、定期実行、デプロイを開始するものではない。
- 無料版は追加の外部サービス利用料を発生させない設計。既存Mac、回線、電力、作業時間、利用中のCodex等の費用を含めた総費用がゼロになるという意味ではない。
- 工程、処理件数、評価ルール、予算上限は実装に向けた仮置き。確定した納期・発注・性能保証ではない。
- 実績・会社予想・外部予想・独自シナリオを分ける。価格計算は円・分割基準・希薄化の扱いをそろえる。
- INFORICHは着想源であり、モデルの配点調整や成績評価には使わない。
- 新しい時点で設計・調査を更新する場合は、新しい日付フォルダを作る。
