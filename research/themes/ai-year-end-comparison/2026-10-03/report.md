## 7. 判断の軸のチェックリスト（質問形式）

読者が自分で選ぶための問い。答えは人によって違ってよい。

**目的とリスク許容度**
- [ ] 年末に、投資額のうち最大いくらまでの損失なら受け入れられるか。それは第4・5節の2σの下限（例：単独のキオクシアで−666万円/1,000万円、既存調査の3社で−535万円）より大きいか、小さいか。
- [ ] 狙いは「AI相場の上げ幅を最大限に取る」ことか、「AIに乗りつつ値動きを抑える」ことか。前者ならβ・ボラの高い銘柄が、後者なら低ボラ銘柄を含む組み合わせが候補になる。両立はしにくい（第5-3節）。
- [ ] 年末に必ず売るのか、年末は見直しの時点にすぎないのか。

**決算イベントの集中**
- [ ] 選んだ銘柄の決算日はいつか。10/27〜10/30に何社が重なるか。決算をまたいで持つか、決算前に一部を減らすか。
- [ ] 顧客・同業の決算（TSMC 10/15、Sandisk 10/29、NVIDIA 11/17頃、Micron 12月）が自分の銘柄にどう波及するか理解しているか。
- [ ] 決算日を会社のIRで確認したか（本稿で「未確認」とした銘柄は特に）。

**バリュエーション**
- [ ] 実績PER・予想PERのどちらで比べるか。会社予想・市場予想・提供元の予想を混ぜていないか（第2-1節の注）。
- [ ] 低いPER（キオクシア・Micron・SK hynix）を「割安」と読むか、「利益のピークを織り込んだ」と読むか。高いPER（イビデン・AMD・アドバンテスト）の銘柄は、決算での上方修正が続く前提を置いているか。

**需給**
- [ ] 大株主の売却・売出し（キオクシアの東芝・ベイン系、ADR上場の思惑）、転換社債（アドバンテストのCB、転換価額36,000円【報道】）、自社株買いの有無を確認したか。
- [ ] 指数イベント（10/30・11/30のTOPIX、11/30のMSCI、12/11のメジャーSQ、日経平均の構成比率）が保有銘柄に関係するか。
- [ ] 信用買い残が多い銘柄（キオクシアは高水準との報道）では、急落時に投げ売りが値動きを増幅しやすいことを知っているか。

**相関と分散**
- [ ] 選んだ2〜3銘柄は同じサブテーマに偏っていないか。偏っている場合、実質的には「1銘柄を持つのとあまり変わらない」（分散比0.88〜0.95）ことを受け入れるか。
- [ ] 相関は下げ相場で高まる。9月中旬の急落では、サブテーマを問わずそろって下げた。平常時の相関の低さを当てにしすぎていないか。

**為替（海外株を含める場合）**
- [ ] 円高が進めば、株価が横ばいでも円建ての損益は減る。ドル円の年率ボラ約8%は、60営業日で1σ約±4%に相当する【独自計算】。
- [ ] 為替ヘッジをするか（個別株では通常ヘッジされない。ヘッジ付きの投資信託・ETFは別の商品になる）。
- [ ] 日本株の中にも、円安で利益が増える輸出企業（アドバンテスト：1円の円安で通期営業利益+53億円【会社予想】、キオクシア：1円で四半期営業利益約130億円【会社予想】）がある。円高はこれらにも逆風になる。

**海外株に特有の論点（一般論）**
- [ ] 取引時間：米国株は日本時間の夜（夏時間の10/31までは22:30〜翌5:00、11/2以降は23:30〜翌6:00）。韓国株は日本時間9:00〜15:30、台湾株は10:00〜14:30（時差1時間）。日中に値動きを見られるか、夜間の急変に対応できるか。
- [ ] 決算の時間外反応：米国の決算の多くは引け後に出て、時間外取引で大きく動く。日本の証券会社で米国株の時間外取引ができるか、損切りの注文方法（逆指値の有無）を確認したか。
- [ ] 売買単位・取扱い：米国株は1株から買えることが多い。台湾株・韓国株の個別銘柄は、日本の証券会社では取扱いが限られる。楽天証券は台湾の個別株（TSMCを含む約50銘柄）の取扱いを2026年12月から始める予定と発表している（2026-08-21告知、手数料は約定代金の1.1%）。韓国の個別株はSBI証券が扱っているとの情報があるが、SK hynixの取扱いは公式ページで確認していない。TSMCは米国ADR（TSM）、SK hynixは米国ADR（2026-07-10上場）でも売買できる。ADRは原株と価格がずれることがある。
- [ ] 流動性：米国の大型株は売買代金が非常に大きいが、時間外取引は薄く、値が飛びやすい。
- [ ] 税金（一般論のみ）：日本の上場株式の譲渡益・配当は原則20.315%。外国株の配当は現地で源泉徴収され（米国株は通常10%、韓国株は租税条約で原則15%）、日本でも課税される。二重課税は、確定申告の外国税額控除で一部調整できる場合がある。NISAの成長投資枠では、日本の税は非課税でも外国の源泉税は戻らない。具体的な扱いは証券会社・税務署・税理士に確認すること。
- [ ] 為替手数料：円→ドル→円の往復で為替スプレッドがかかる。

**流動性・コスト（日本株）**
- [ ] 売買代金が小さい銘柄（信越化学397億円、住友電工404億円、日立540億円、ディスコ802億円／20日平均）は、大型半導体株より値が飛びにくい一方、急落時の売り抜けは主力株ほど容易ではない場合がある。
- [ ] 売買手数料・税金・為替コストを差し引いた損益で考えているか。

**ルールを事前に決める（一般論）**
- [ ] 損切りの水準（例：買値から何%、または何万円）と、利益確定の水準を、買う前に決めたか。決算の直後のように感情が動く場面で判断を変えないための仕組みがあるか。
- [ ] 買うタイミングを分けるか（一度に買うか、数回に分けるか）。
- [ ] 年末の時点で何を見て「持ち越す／売る」を判断するか。
- [ ] 1銘柄が大きく上がって比率が偏ったとき、配分を戻すか。

## 8. 方法・出所・限界

- **データ**：Yahoo Finance公開エンドポイント（chart：分割調整済み日足2年、fundamentals-timeseries：株式数・EPS）。2026-10-03に取得し、`working/`（Git対象外）に保存。`python3 compare.py --offline`で同じ数値を再計算できる（[compare.py](compare.py)、出力は[compare-output.txt](compare-output.txt)と`working/compare-results.json`）。
- **1年の窓**：2025-10-02終値→2026-10-02終値（日本株の日次242本）。[キオクシア版](../../../companies/285A-kioxia/2026-10-03/stock-drivers.md)と同じ窓で、キオクシアのボラ（60日120%・1年112%）、日次β（60日3.42・1年2.49）、キオクシア〜アドバンテストの日次相関（60日0.68・1年0.58）、キオクシア〜イビデン（0.71・0.62）、アドバンテスト〜イビデン（60日0.73）は既存レポートと一致する。
- **円換算**：海外株は現地通貨の終値×同じ日付以前で直近の為替（Yahooの日足終値。ドル円はJPY=X、台湾ドル円TWDJPY=X、ウォン円KRWJPY=X）。米国の終値と為替の時刻は厳密には一致しない。
- **TOPIX連動ETF（1306）**：提供元のデータに2026-03-31の欠損（1/10の値）があったため、本稿では使っていない。
- **ボラ・σ幅の限界**：過去1年の値動きの大きさが続くことを前提にした機械的な幅。決算・政策・地政学の大きなイベントでは、この幅を超える動きが起き得る。ドリフト（期待リターン）は0と置いた。
- **相関の限界**：週次は観測数が少なく、外れ値（決算週）に弱い。時差の影響は週次化でも完全には除けない。
- **会社予想EPS**：通期予想を出していない銘柄（キオクシア・東京エレクトロン〈10/30に開示予定〉・ディスコ・ソフトバンクG）と海外株は「—」。海外株は提供元の予想PER（外部予想ベース）のみ。
- **イベント日付・会社予想**：補助調査（2026-10-03）で、各社のIRカレンダー・決算短信・会社リリース、JPX・FRB・日銀・BLS・MSCIの一次資料を確認したものを「確認済」とした。会社が未告知のものは「未確認」。
- X（Twitter）APIは費用上限のため使っていない。有料API・秘密情報も使っていない。他者の文章は要約し、長く引用していない。
