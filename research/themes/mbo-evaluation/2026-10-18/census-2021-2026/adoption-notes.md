# Astraレビューの採否と反映結果

2026-10-18。対象は[Astraの独立レビュー](astra-review.md)。レビュー本文は読取時点の版の記録として保持し、以下を最終版へ反映した。

| 指摘 | 判断・反映 |
| --- | --- |
| 追加3項目 | 修正採用。応募合意と下限到達、条件の存在と充足、価格差と明示的異論を分離。基準を候補詳細にも表示 |
| 点数・確率・監視昇格 | 見送り。4軸と割安度・情報確度・手動作業区分を維持。根拠が増えたことをMBO確率の上昇としない |
| 検証状態の表記ゆれ | 明示的な許可集合で正規化し、元状態も保存。文字列の先頭がverifiedというだけでは承認しない |
| 同一原本IDの引用位置の差 | 同じURL・公開日かを検証し、原本同一性と複数の引用位置を分離。別URL・別公開日の衝突は拒否 |
| 非TOBの結果 | 方式と準ずる区分を保存し、TOB成否は対象外。上場廃止実績と公表日を別項目に保持 |
| 上廃のみの実績確認 | TOB成否は未確認、結果日を作らず、実績と原本未確認を明記。公表済TOB失敗と完了を混ぜない |
| 実績上廃日の出典欠落 | 年別台帳の各実績へ明示出典ID・位置を補完。結果原本と上廃原本を別リンクで表示し、詳細の原本一覧にも収集 |
| 障害の証拠役割 | 結果の直接の要件、取引所の事後整理、公表された実施条件、仮定の中止条件を保持・表示 |
| 価格差と異論 | サカイ初回の市場価格差は独立分類に訂正。市場株価超過だけを価格への異論の根拠へ対応付けない |
| 関連項目タグ | スポンサー支援から資金合意、市場評価から価格異論への自動対応を外した。残るタグも調査項目の参照であり状態の確認・加点ではない |
| 動機頻度の分母 | 正式公表と本文確認済みの集合を使用。多重分類、抽出の深さの差、0件の解釈を明記 |
| 初報と正式公表 | 旧詳細との時点補強はコード＋正式日が一致するエピソードだけ。Snow2/16の報道確認と2/20正式、INFORICH同日の報道確認を維持。全件で初報日を復元したとは表示しない |
| 旧詳細の初回→再実施 | 主台帳では各回を分離。旧9社の詳細は同社の別参考欄に残し、主台帳の結果へ丸ごと上書きしない |
| 除外台帳の理由・原本 | exclusion_reason/source_urlを含む表記に対応。会社明示の非MBOと、分類未確定のため主表未算入とを文言で区別 |
| 年別・市場別の範囲 | 東証公式17/11/17/18/31、全国区分、非TOB内数を表示。数値一致を定義一致の証明にはしない。全国の完全捕捉未確認を折り畳みの外へ表示 |
| 比較群 | 設計を採用。基準日時点の全上場母集団・観測窓・他の買収・未完了・欠測を先に固定。今回の採点を作るために選択事例だけで精度を出す処理は実装しない |

現在候補の再評価は[検証JSON](current-evaluation.json)に保存。19候補の新3論点はすべて未確認のまま。入力レコードID、株価・財務・価値計算・イベント・手動作業判断、旧runのバイト列が保たれることを検証した。

この反映は調査支援の確認項目を強くするものであり、MBO予測の的中率を実証したものではない。全上場の対照群と未使用期間による校正は未実施。
