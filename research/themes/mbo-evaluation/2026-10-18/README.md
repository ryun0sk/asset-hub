# MBO候補の評価方法と過去事例

調査・設計日：2026-10-18（日本時間）。過去のMBOの公表理由、成立・不成立、検討見送りを調べ、現在の候補評価に採用する項目と、まだ検証できない項目を分ける。

ユーザー指定のGPT-6 Astraと設計判断を相談し、一次資料による事例確認と独立レビューを行う。少数の選択事例は論点の発見に使い、発生確率・予測精度・要因の因果効果を推定したものとは扱わない。
