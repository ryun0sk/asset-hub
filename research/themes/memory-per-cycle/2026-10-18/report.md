# なぜメモリ株のPERは低いのか――SK hynixとキオクシア

調査・一次資料確認：2026-10-18 JST。株価による比較は前回の2026-10-15保存値に固定し、現在株価を新規取得した分析ではない。数値の再現は[計算結果](analysis-calculations.json)を参照。

## 結論

【独自判断】低PERを説明する中心は、**AI需要の成長を否定していることより、現在の高い販売価格・利益率が何年間続くかの不確実性**である。将来の減益を含む長期利益に対して株価が付く一方、分母は好況期の利益になっている。ただし、株価から市場全体の減益予想・確率を一意に特定したわけではない。

さらにSK hynixは、**直近実績に多額の配当収入・金融商品評価益が含まれる**。低い実績PERをすべてHBMやメモリ販売の反復利益へ帰属させてはいけない。外部予想PERの調整内容は別途確認が必要で、実績の特殊利益と外部予想を混ぜない。

キオクシアの春の高PERは逆の現象だった。**株価が将来の増益を先取りしたのに、実績TTM EPSには低利益だった過去の四半期が残っていた。** その後の決算でEPSが大幅に更新され、株価が上がった日にもPERは急低下した。秋の追加低下は株価下落が主因で、同じPER低下でも原因が異なる。

## 1. 最初に、3～4倍台は何のPERだったか

前回の低倍率は外部予想に基づく数字であり、実績PERとは異なる。

| 対象・10/15保存株価 | 利益の基準 | EPS | PER |
|---|---|---:|---:|
| キオクシア・12,880円 | 2026/3期の会社公表・希薄化後通期実績を分割調整 | 336.38円 | 38.29倍 |
| 同上 | 2026/6までの独自再構成TTM・希薄化後概算 | 832.24円 | 15.48倍 |
| 同上 | 2027/3期IFIS予想・前回取得表示 | 3,443円 | 3.74倍 |
| SK hynix・1,262,000ウォン | 2025/12期会社公表・基本通期実績 | 62,044ウォン | 20.34倍 |
| 同上 | 2026/6までの基本EPS差分によるTTM近似 | 229,700ウォン | 5.49倍 |
| 同上 | 2026/12期S&P Global系・調整後外部予想の前回取得値 | 355,218.90ウォン | 3.55倍 |

SKのTTM近似は62,044－前年上期21,890＋当年上期189,546。期中株数変化があるので厳密なTTM加重平均分母ではない。キオクシアの希薄化後TTMとの完全な同条件比較でもない。SKの保存グラフ用TTM227,575ウォンを同じ株価へ当てる参考値は5.55倍で、この小差よりも利益期間・特殊利益の違いが大きい。

キオクシアのIFIS予想は10/15の更新時刻による差があり、前回の遅い集計から推計したPERは約3.80倍。ただし新しい公表EPSを確認した数字ではないため、表では取得済みの3,443円を明記した。SKの予想サイトはnon-GAAP adjustedと明示するが、投資関連益をどの範囲で除外したかの調整表は確認できない。**3.55倍を「特殊利益がすべて除去済みの利益倍率」と断定しない。**

出所：[前回IFIS照合・取得時点](../../../companies/285A-kioxia/2026-10-15/per-analysis.md)、[SK会社半期報告書・基本EPS注27](https://www.sec.gov/Archives/edgar/data/2120882/000119312526354777/d147827d6k.htm)、[SK外部予想の定義](https://stockanalysis.com/quote/krx/000660/forecast/)。今回のウェブ取得では外部統計ページのキャッシュ時点に差があったため、表の株価・予想を10/18の最新値とはしていない。

## 2. 共通する低PERの理由――数量成長と超高利益の継続は別

【会社実績】キオクシアの2026年4～6月は、ドル建てASPが前四半期比約70%上昇した一方、ビット出荷は一桁台前半増だった。同条件ASPと製品構成込みASPの伸びも同程度。売上増と利益増の中心は、出荷数量や高付加価値化だけでなく販売価格の急上昇だった。売上原価も増えており、単純に「原価が下がって儲かった」と説明しない。[Q1公式説明・p9～10](https://ssl4.eir-parts.net/doc/285A/ir_material_for_fiscal_ym4/209425/00.pdf)

【会社実績】SKの同じ四半期も、DRAM数量は小幅増に対してASPは30%台半ば上昇、NAND数量は10%台半ば増に対してASPは50%台半ば上昇。HBMの差別化だけでなく、DRAM・NANDの価格が利益を押し上げている。HBMはDRAMに含まれ、全社をHBM専業と扱わない。[半期報告書・Price Trends for Major Products、注21](https://www.sec.gov/Archives/edgar/data/2120882/000119312526354777/d147827d6k.htm)

【会社のリスク認識】キオクシア有報は、競合増産・顧客在庫でNAND価格が急速に下落し得ること、価格決定力が限られること、多額の設備投資・研究開発に伴う固定費によって減収の利益影響が増幅することを説明している。[有価証券報告書英訳・冊子p88、91](https://www.kioxia-holdings.com/content/dam/kioxia-hd/en-jp/ir/library/securities/asset/Annual-Securities-Report-FY2025-EN.pdf)

【独自解釈】AI向けの販売数量が増え続けても、供給増などで単価が下がれば利益は減り得る。高い価格を前提にしたEPSへ30倍を付けると、「その高収益が長く続く」ことまで強く織り込む。実際に将来使える現金は、設備更新・増設・研究開発・運転資金・税支払にも左右される。このため、PERだけでなく投資後CFと平常時利益を併用する。

例えば10/15保存値の予想PER3.74倍でも、株価固定で利益が半分なら7.48倍、4分の1なら14.96倍になる。これは減益予想や市場の織込みを特定したものではなく、低PERが利益水準にどれだけ依存するかの条件計算である。

一方、直ちに市況崩壊を見込む根拠でもない。TrendForceの9/30見通しでは4Q26のNAND契約価格は前四半期比15～20%上昇、通常DRAMも10～15%上昇とする。**短期の逼迫継続と、数年単位では高利益率を割り引く評価は両立する。**[TrendForce原調査](https://www.trendforce.com/presscenter/news/20260930-13258.html)

## 3. SK hynix固有の注意――実績純利益には大きな金融収益

【会社実績】2026年4～6月の売上は79.3187兆ウォン、営業利益60.5426兆ウォン、営業利益率は約76%。連結純利益は93.9226兆ウォンで、売上を上回る。メモリ販売の営業利益だけで説明する数字ではない。[7/29会社決算発表](https://news.skhynix.com/en/q2-2026-business-results/)

【連結注記】SEC半期報告書注24の同四半期は、配当収入10.027945兆＋金融商品評価益53.237425兆＝63.265370兆ウォン。税前利益は122.708355兆、親会社株主帰属利益は93.820236兆。上期では同種の配当収入・評価益の合計が77.158541兆ウォンある。[SEC半期報告書・注24、26、27](https://www.sec.gov/Archives/edgar/data/2120882/000119312526354777/d147827d6k.htm)

これらは税前の金融収益で、親会社帰属純利益から全額をそのまま引けない。評価益は当期の現金収入でもなく、配当収入と分ける必要がある。一次注記から全額をキオクシア投資由来と特定したり、キオクシア個別の税引後寄与額を確定することはできなかった。したがって本レポートでは正式な特殊要因除外EPSを計算しない。

評価益を恒常利益から区別することは、保有金融資産の価値をゼロとみなすことではない。保有資産・現金の価値は別に評価する。問題は、その資産価値の増加を毎年繰り返すメモリ販売利益とみなし、高いPERを掛けて恒久化することである。

【独自判断】SKの低い実績PERには、強い本業の利益に加え、反復性の低い金融収益も効く。外部調整後予想の3.55倍は別の計算であり、その数字全体を金融評価益だけで説明することもできない。見るべきなのは特殊利益を分離した営業利益、DRAM/NANDのASPと数量、投資後CFである。

財務危機だけで安くなっているとみるのも適切ではない。8/19会社発表は純現金約69兆ウォンと、40兆ウォンの自社株買い・消却、2025～27年累計FCFの50%超を還元する方針を説明している。[公式還元方針](https://news.skhynix.com/en/share-buyback-and-retirement/)

## 4. キオクシアのPERが一時上がった原因を数字で分解

以下は[10/15保存・公式資料からの再構成系列](../../../companies/285A-kioxia/2026-10-15/eps-per-history.json)。すべて分割後・円建て。TTMは利益・希薄化分母から再構成した概算で、会社公表TTMそのものではない。引け時点の決算は次の営業日から反映する。

| 2026年 | 株価 | TTM EPS | 実績PER | 主な変化 |
|---|---:|---:|---:|---|
| 1/5 | 3,783円 | 96.16円 | 39.3倍 | 年初 |
| 3/31 | 6,360円 | 101.91円 | 62.4倍 | 実績には低利益期が残る |
| 4/30 | 12,520円 | 101.91円 | 122.9倍 | EPS一定のまま株価が約97%上昇 |
| 5/13 | 16,833円 | 101.91円 | 165.2倍 | 実績PERの山 |
| 5/15 | 14,817円 | 101.91円 | 145.4倍 | 同日決算の反映前 |
| 5/18 | 17,150円 | 336.38円 | 51.0倍 | 通期実績がTTMへ入る |
| 6/22 | 36,233円 | 336.38円 | 107.7倍 | 株価上昇による第2の山 |
| 7/31 | 15,500円 | 336.38円 | 46.1倍 | 同日Q1決算の反映前 |
| 8/3 | 16,387円 | 832.24円 | 19.7倍 | Q1実績がTTMへ入る |
| 10/2 | 19,300円 | 832.24円 | 23.2倍 | 保存版グラフの株価終点 |
| 10/15 | 12,880円 | 832.24円 | 15.5倍 | EPS一定のまま株価下落 |

1/5→5/13は株価が約4.45倍、TTM EPSは約1.06倍なので、PERが約4.20倍になった。**利益の悪化で分母が崩れた山ではなく、株価の先行が支配的**である。

その先行を支える公開材料は存在した。2/12会社説明は1～3月の全用途ASP急上昇と大幅増益を予告。3/17にはNVIDIA Storage-Next向け高速SSD開発を発表。3/31のTrendForceも4～6月のNAND契約価格70～75%上昇を予想していた。ただし、各材料の株価寄与率を特定した分析ではない。3/17製品は当時の巨額売上実績でもなく、6/2 Investor Dayを5/13以前の上昇原因にはしない。

出所：[2/12会社短信](https://www2.jpx.co.jp/disc/285A0/140120260212556330.pdf)、[3/17製品発表](https://www.kioxia.com/ja-jp/business/news/2026/20260317-1.html)、[3/31 TrendForce](https://www.trendforce.com/presscenter/news/20260331-12995.html)。

5/15→5/18は株価が15.7%上がった一方、EPSが3.30倍となり、PERは145.4→51.0倍へ下がる。7/31→8/3も株価5.7%上昇に対してEPS2.47倍で、PER46.1→19.7倍。**PERの縦落ちを株価暴落と読むのは誤り。**[5/15公式通期短信](https://www2.jpx.co.jp/disc/285A0/081220260515537803_tse-acedifsm-285A0-202605153285A0-ixbrl.htm)、[7/31公式Q1短信](https://www2.jpx.co.jp/disc/285A0/081220260731505265_tse-qcedifsm-285A0-202607313285A0-ixbrl.htm)

一方、10/2→10/15はEPSが832.24円のままで、株価19,300→12,880円、PER23.2→15.5倍。ここは株価とPERがともに約33.3%低下しており、直近の安さには株価下落もはっきり効いている。

## 5. 保存版グラフには、景気以外の表示要因もある

図の保存系列では5/13ピークが約175.4倍。これは同日の株価16,833.33円を、保存EPS95.9667円で割ったもの。2025/12期TTMの入力がなく、古い2025/9期を持ち越している。2/12開示も含む上の再構成EPS101.9058円なら165.2倍で、保存図は約6.2%高い。

さらに保存図は多くのTTMを「期末＋45日から既知」とする前提で、5/15にEPSを更新する。公式発表は5/15引け時点であり、本レポートの終値比較は翌5/18から更新する。7/31についても保存図は当日、再構成系列は翌営業日8/3。SKも原則期末＋45日で、2026/6期TTMの段差は8/14になるが、実際の発表は7/29。**図の段差の日付を、そのまま市場が反応したニュースの日と扱わない。**

出所：[保存版の計算前提](../../ai-supply-chain/2026-10-18/README.md)、[元の前提詳細](../../ai-supply-chain/2026-10-03/README.md)、[SK公式発表](https://news.skhynix.com/en/q2-2026-business-results/)。今回は原因分析にとどめ、過去のグラフ・アーカイブを変更していない。

## 6. 私なら、低PERをどう評価するか

【独自判断】**AIによるメモリ需要増加は構造的だとみるが、足元の高いASP・利益率がそのまま何年も続くとまでは判断しない。** キオクシアではASP約70%増に対し数量は一桁増、SKでは金融収益が大きい。現在のEPS全額へ高い成長株倍率を付ける根拠は弱い。一方、需要の底上げ・製品差別化・長期契約が従来より利益の底を上げる可能性もあり、「メモリだから低PERが妥当」とだけ片づけるのも不十分である。

キオクシアの6/2公式Q&AはCY2028出荷物量50%のLTAカバー目標を説明するが、固定価格・価格下限・解約条件の詳細は非開示。SKも約10顧客とのLTAを説明するものの、数量契約を利益率保証と同一視しない。[キオクシア公式Q&A](https://www.kioxia-holdings.com/content/dam/kioxia-hd/en-jp/ir/library/event/asset/Investor-Day-2026-Eng-QA.pdf)、[SK会社説明](https://news.skhynix.com/en/q2-2026-business-results/)

増産リスクにも時間軸がある。SKの8/7発表ではY2最初のクリーンルームは2029年6月、M17は2028年12月。キオクシア北上Fab3もFY2029の稼働を目指す。将来の供給増は評価へ織り込めても、これらの工場だけを根拠に来四半期から供給過剰になるとは言えない。[SK公式設備計画](https://news.skhynix.com/en/fab-facility-investment-2026/)、[キオクシア公式工場発表](https://www.kioxia.com/en-jp/about/news/2026/20260827-2.html)

次の確認はSKが10/28、キオクシアが10/30の決算。見る順番は、①ASPと数量を分けた実績、②特殊利益を除く本業の利益、③設備・税・運転資金を払った後のCF、④先の契約の価格条件と供給計画である。EPSが高いままでもASP上昇率が鈍る時に、数量・コスト改善が補えるかが焦点となる。[SK決算日公告](https://www.sec.gov/Archives/edgar/data/2120882/000119312526420934/d413172d6k.htm)、[キオクシア公式IR](https://www.kioxia-holdings.com/en-jp/ir.html)
