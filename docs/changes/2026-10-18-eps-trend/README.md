# EPSの推移タブ（2026-10-18）

「PERの推移」の隣に独立した「EPSの推移」（`#ai/eps`）を追加した。既存の「EPS予想・決算」では四半期・通期の実績と予想、決算日を引き続き確認できる。

- 保存済み46社のTTM EPSを、その日までの公表済みデータで表示。公表日の前へ新しいEPSを遡及適用しない。
- 実額はEPSの現地通貨別にグラフを分け、為替換算しない。EPSの0・赤字を線形軸に保持する。
- 指数は選択開始日のEPSが正値の企業だけ開始＝100とする。開始日に欠損・0・赤字なら指数・増減率を算出しない。
- 工程の複数選択・企業のON/OFF・既存の期間ボタンに追従。欠損・失効は線を切り、GE Vernovaとイビデンの一時利益を注記する。
- 既存43社は10/3版の保存値、発電3社は10/18確認値を使用。PER画面上部の7社月次表とは資料時点を区別する。追加取得・株価や予想の更新は行っていない。
