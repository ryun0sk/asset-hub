# INFORICHの事例追補と収録範囲の明記

2026-10-18。ユーザーの未掲載指摘を受け、[過去事例タブ](https://asset-hub-pvgbytjsqa-an.a.run.app/#mbo/cases)へINFORICHを追加した。

会社と取引所の一次資料で、報道後の公式検討確認、正式MBO公表、TOBの結果、上場廃止実績を区別して確認する。公表資料が遡って説明する交渉や経営判断は、公表前の予測材料に置き換えない。
