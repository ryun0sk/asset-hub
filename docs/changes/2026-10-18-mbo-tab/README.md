# Asset HubのMBO調査タブ

2026-10-18に、普段の非公開Asset Hubへ「MBO調査」を反映した。[本番のMBOタブ](https://asset-hub-pvgbytjsqa-an.a.run.app/#mbo/candidates)から候補、公表案件、週次履歴を切り替えられる。実企業の初回調査は未実施で、現在の本番は結果の登録待ち。架空デモはMac内で検証し、本番へ投入していない。

計算・CSV取込・原本・SQLiteはMacに置き、クラウドは選別済みの週次結果だけを読む。週次結果は[書出しと反映手順](../../mbo-weekly.md#普段のasset-hubへ週次結果を反映する)で更新でき、毎週のコード再デプロイは不要。閲覧APIからの計算・取込・書込は提供しない。

専用ブラウザタブや別originのiframeを開く方式から、Asset Hub本体のナビ・見出しと同一origin APIを使う構成にした。MBO内の画面移動では検索・選択を保持し、別の機能へ移ると未完了の取得とイベントを破棄する。CSSはMBOの内容内に限定し、既存画面へ適用しない。

本番は既存イメージを固定した上でMBO関連10ファイルだけを更新した。ビルド内で変更前6ファイルと新規4ファイルの状態を照合し、それ以外の326ファイルが同じ内容であることを確認した。調査資料・原本・DB・架空データは今回のビルドに含めていない。IAP、閲覧者、実行サービスアカウント、環境変数、インスタンス台数を維持している。

Python 207件（既存の環境依存8件skip）、JavaScript 128件、デザイントークン、アーカイブ8版を確認した。本番Chromeで候補・公表案件・週次履歴の空状態、EPS推移・資産サマリーとの往復、エラーがないことを確認した。ローカルでは架空デモの詳細・株価欠測・検索状態の保持も検証済み。
