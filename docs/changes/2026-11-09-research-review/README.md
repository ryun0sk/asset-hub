# 11月6日・9日調査の追加とレビュー

キオクシア、AI関連46社、メモリ株の利益感応度、割安104社スクリーン（2026-11-06）とJT（2026-11-09）の調査を追加する。株価・予想・投資判断は各調査日時点の保存値で、レビュー時に価格を再取得していない。

## レビューで修正した点

- AI46社の集計は、対象一覧と株価入力がそれぞれ46件かつ一意であることを辞書化・出力前に検証する。重複・欠落がある入力を拒否し、保存済みJSON/CSVの再現と併せて回帰テストを追加した。
- 割安スクリーンは、正常化PERによる失格と希薄化の確認不足を区別し、CSV・本文の群分け、件数、総合点の四捨五入をそろえた。株価や持続性・割安度の採点自体は変更していない。詳細は[調査README](../../../research/themes/undervalued-screen/2026-11-06/README.md)。
- JTのPythonコードはローカル再計算用と明記し、非公開ダッシュボードで配信しない拡張子へのリンクを保存JSON・再計算手順へのリンクへ置き換えた。
- カタログの資料名はREADME表の主対象から決める。同じ行にある別テーマの過去資料リンクへ名前を流用し、10月の将来利益比較に11月の最新決算レビューの名前が付く問題を修正した。
- 費用画面のテストは、表示する記録日からスナップショット期間を作る。固定された2026年10月の期間によって、11月以降にHTMLエスケープの検証が失敗する問題を解消した。

実装担当とは別の担当者が修正を再レビューし、修正対象の追加指摘が残っていないことを確認した。

## 検証

- 保存入力だけを用いたキオクシア・メモリ・AI候補・JTモデルの再現と、JSON/CSV・本文の整合を確認。
- ローカル文書リンク、HTTP配信の許可リスト、カタログ生成、アーカイブハッシュ、デザイントークン、Python・Nodeの既存テストを確認。
- 確定した件数と最終結果は[checks.json](checks.json)へ記録する。

資産の残高はGitへ含めず、既存の非公開stateに保存する。[資産データの運用](../../assets.md)。11月9日の記録リンクだけをルートREADMEへ反映した。

本番にはレビュー・マージ済みソースからCloud Runイメージを構築し、既存のIAPと閲覧者設定を維持して反映する。資産stateの更新はアプリイメージと別に管理する。
