計算ルールを実企業向けに補強した。余剰現金と株数の独自推計を会社実績から区分し、元の実績株数も併記。同じBS日のcash/debt/NCIを使い、欠測を過去値で自動補完しない。将来の運転資本減少は反復せず、設備投資は減価償却費を下限とする保守的仮定。これらはMac側の計算変更であり、クラウドは保存結果の読取りを継続する。

追加の有料API・定期ジョブは作成していない。既存のGCS/Cloud Runの利用枠を使う。調査は今後もユーザーの週次依頼でMac上で行う。
